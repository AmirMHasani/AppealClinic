## Outreach principles (non-negotiable)

1. **Validation, not sales** — Amir is an MD founder; ask peers for help proving the tool before any clinic is charged.  
2. **De-identification first** — Names, DOB, address, phone, email, SSN, full MRN/member ID stripped or replaced (`SHADOW-###`) **before** anything is shared.  
3. **No EHR access** — No portal login, no remote desktop, no “just give us Epic.” Packet PDF/scan or printed redacted bundle only.  
4. **Nothing billed** — Shadow run is free; clinic may ignore or optionally use drafts.  
5. Prefer practice manager / PA coordinator / billing lead who already fights biologic denials.

## Email — subject + body

**Subject options (pick one):**  
- `Quick ask from a Philly MD — de-identified biologic denial packets (not a sales pitch)`  
- `Phase 2 validation help: 10–15 redacted derm biologic denials?`  
- `Fellow MD building an appeal-draft tool — need shadow cases, zero PHI`

**Body:**

```
Hi [First name / Practice Manager],

I’m Amir Hasani, MD — I’m building AppealClinic, a tool that drafts prior-auth / medical-necessity appeals for dermatology biologics (PsO, AD, HS, etc.). Before we charge any clinic, we’re doing a quiet Phase 2 “shadow” validation on real (already denied) packets.

Could your team share roughly 10–15 already-denied PA or appeal packets with all identifiers removed?

What we need (after redaction):
• Payer + denial reason / date
• Drug, indication, dose
• Clinical bullets (failed therapies, severity scores like BSA/IGA/Hurley, relevant labs)
• No names, DOBs, addresses, phones, emails, SSNs, or full MRNs/member IDs

What we will not do:
• No EHR / portal access
• Nothing billed — this is validation only
• We won’t market your practice or submit anything to a payer ourselves

You’ll get the drafts back for optional use (edit or discard). Happy to sign a short one-pager on de-identification / no PHI retention if that helps.

If a practice manager or PA coordinator owns biologic denials, I’m happy to loop them in. Even 5 strong packets would help us start.

Thank you for considering — I know how painful these denials are.

Warmly,
Amir Hasani, MD
Founder, AppealClinic
[phone] · [email] · [calendar link optional]
```
